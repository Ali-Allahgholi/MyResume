### ✨ قابلیت‌ها و ویژگی‌ها

- 🌐 **پشتیبانی دو زبانه (فارسی و انگلیسی):** سوییچ آنی زبان با چینش راست‌به‌چپ (RTL) و چپ‌به‌راست (LTR) و فونت اختصاصی وزیرمتن برای فارسی.
- 🌓 **حالت تاریک و روشن (Dark / Light Mode):** پشتیبانی کامل از تم تیره و روشن همراه با افکت‌های نورپردازی محیطی داینامیک.
- 📄 **مشاهده و دانلود رزومه:** دارای مودال شیک برای پیش‌نمایش مستقیم رزومه PDF و قابلیت دانلود فایل رزومه.
- 💻 **کامپوننت ترمینال تعاملی:** همراه با انیمیشن تایپ و آیکون‌های تعاملی فناوری‌ها.
- 📱 **کاملاً واکنش‌گرا (Responsive):** سازگاری بی‌نقص با انواع دستگاه‌ها (موبایل، تبلت و دسکتاپ).
- ⚡ **سرعت و عملکرد فوق‌العاده:** بهینه‌سازی‌شده با Vite و معماری کامپوننت‌محور سریع React 19.

#### روش دوم: اجرای پروژه روی سیستم شما (لوکال)

##### ۱. پیش‌نیازها
مطمئن شوید که ابزار [Node.js](https://nodejs.org/) (ترجیحاً نسخه 18 یا بالاتر) و `npm` یا `yarn` روی سیستم شما نصب باشد.

##### ۲. کلون کردن ریپازیتوری گیت‌هاب
ترمینال سیستم خود را باز کرده و دستور زیر را برای دانلود پروژه اجرا کنید:
```bash
git clone https://github.com/Ali-Allahgholi/MyResume.git
```

##### ۳. ورود به پوشه پروژه
```bash
cd MyResume
```

##### ۴. نصب پکیج‌ها و پیش‌نیازها
دستور زیر را اجرا کنید تا وابستگی‌های پروژه نصب شوند:
```bash
npm install
```

##### ۵. اجرای سرور توسعه (Local Dev Server)
دستور زیر را وارد نمایید:
```bash
npm run dev
```

پس از اجرای این دستور، ترمینال لینکی مشابه زیر به شما نمایش می‌دهد:
```text
  VITE v6.x.x  ready in 250 ms

  ➜  Local:   http://localhost:5173/MyResume/
  ➜  Network: use --host to expose
```
آدرس `http://localhost:5173/MyResume/` (یا کلید `o + Enter` در ترمینال) را در مرورگر خود باز کنید تا سایت را مشاهده کنید.

- 🌐 **Bilingual (English & Persian):** Instant toggle between English (LTR) and Persian (RTL) with appropriate typography (Vazirmatn & Outfit).
- 🌓 **Dark / Light Mode:** Adaptive ambient lighting effects with smooth theme transitions.
- 📄 **Resume Modal & Download:** In-app PDF preview and direct download capabilities.
- 💻 **Interactive Hero & Terminal:** Typewriter animation, floating tech stack badges, and interactive controls.
- 📱 **Fully Responsive:** Seamless layout across mobile phones, tablets, laptops, and ultra-wide screens.
- ⚡ **Ultra-Fast Performance:** Built on Vite with zero bloat and optimized bundle sizes.

### 🚀 Getting Started / How to Run

#### Option 1: Live Demo (Recommended)
You can view the live site directly in your browser without installing anything:  
👉 **[Open Live Demo on GitHub Pages](https://ali-allahgholi.github.io/MyResume/)**

---

#### Option 2: Run Locally on Your Machine

##### 1. Prerequisites
Ensure that [Node.js](https://nodejs.org/) (version 18+ recommended) and `npm` are installed on your machine.

##### 2. Clone the Repository
Open your terminal and clone the project:
```bash
git clone https://github.com/Ali-Allahgholi/MyResume.git
```

##### 3. Navigate into the Project Folder
```bash
cd MyResume
```

##### 4. Install Dependencies
```bash
npm install
```

##### 5. Start the Development Server
```bash
npm run dev
```

Open the printed URL in your browser (usually `http://localhost:5173/MyResume/`).

---

### 🛠️ Available Scripts

- `npm run dev`: Starts the local development server with Hot Module Replacement (HMR).
- `npm run build`: Compiles and bundles production-ready assets into the `dist/` directory.
- `npm run preview`: Locally previews the production build.
- `npm run deploy`: Builds and publishes the project to GitHub Pages using `gh-pages`.
